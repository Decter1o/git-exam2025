# Gym Management System

## Описание проекта

Система управления фитнес-клубом (спортивным залом) - веб-приложение для администрирования и управления членством, тренерами, расписанием занятий и посещаемостью.

**Статус**: Учебный проект 2025 года  
**Язык**: PHP 7+  
**БД**: PostgreSQL  
**Фреймворк**: Vanilla PHP (MVC-подобная структура)

---

## Основные возможности

### Для администратора
- **Управление тренерами** - добавление, редактирование, удаление тренеров с фото
- **Управление членством** - создание типов членства с разными сроками и ценами
- **Управление типами тренировок** - определение видов тренировок в клубе
- **Управление расписанием** - составление расписания занятий по дням недели
- **Управление посетителями** - просмотр, редактирование, блокировка/разблокировка членов
- **Аналитика** - статистика по посещаемости и использованию услуг
- **Управление посещениями** - отслеживание входов членов в клуб

### Для посетителей
- **OTP-аутентификация** - вход по номеру телефона с кодом подтверждения (SMS)
- **Просмотр профиля** - информация о членстве и оставшихся посещениях
- **Расписание занятий** - просмотр доступных тренировок
- **Информация о тренерах** - данные о квалификации и контактах тренеров

## Модели данных

### Тренеры (Trainer)
- **id** - уникальный идентификатор
- **name, surname** - имя и фамилия
- **phone_number** - номер телефона
- **training_type_id** - тип тренировки
- **inst, tg, whatsapp** - социальные сети и мессенджеры
- **description** - описание квалификации
- **photos** - фото тренера (одна или несколько)

**Методы**: GetAll(), Create(), Update(), Delete()

### Посетители (VisitorUser)
- **id** - уникальный идентификатор
- **name, surname** - имя и фамилия
- **phone_number** - номер телефона
- **status** - статус (активен/заблокирован)
- **membership** - связь с членством

**Методы**: GetAll(), Create(), Update(), Delete(), Block(), Unblock(), CheckPhoneNumber(), VerifyOTP()

### Членство (GymMembership)
- **id** - уникальный идентификатор
- **membership_type** - тип членства
- **duration** - длительность (дни)
- **price** - стоимость
- **special_group** - специальная группа

**Методы**: GetAll(), Create(), Update(), Delete()

### Типы тренировок (TrainingType)
- **id** - уникальный идентификатор
- **training_name** - название тренировки
- **description** - описание

**Методы**: GetAll(), Create(), Update(), Delete()

### Расписание (Schedule)
- **id** - уникальный идентификатор
- **day_of_week** - день недели
- **start_time, end_time** - время начала и окончания
- **training_type_id** - тип тренировки
- **room_name** - название зала
- **trainer** - тренер
- **category** - категория

**Методы**: GetAll(), Create(), Update(), Delete()

### Посещения (Visits)
- Отслеживание входов посетителей в клуб

### Аналитика (Analytic)
- Статистика по посещениям и использованию услуг

## Установка и настройка

### Требования
- PHP 7.4+
- PostgreSQL 10+
- Apache с поддержкой .htaccess
- curl для отправки SMS

### Шаги установки

1. **Клонируйте репозиторий**
   ```bash
   git clone <repository-url>
   cd localhost
   ```

2. **Настройте конфиг БД** (`config/config.php`)
   ```php
   'db' => [
       'host' => 'localhost',
       'dbname' => 'exampisis',
       'user' => 'postgres',
       'password' => 'qwerty',
       'charset' => 'utf8'
   ]
   ```

3. **Создайте БД PostgreSQL**
   ```sql
   CREATE DATABASE exampisis;
   ```

4. **Импортируйте схему БД** (см. SQL скрипты, если они есть)

5. **Настройте SMS сервис** (config/config.php)
   - Получите API ключ на https://mobizon.kz
   - Обновите конфиг с вашими учетными данными

6. **Проверьте права на папки**
   ```bash
   chmod 755 public/
   chmod 755 logs/
   ```

7. **Откройте приложение**
   - http://localhost (или ваш домен)

## API и Маршруты

Приложение использует AJAX для общения между фронтенд и бэкенд. Основные моделе класс обрабатывают CRUD операции:

### Тренеры
- `Trainer->GetAll()` - получить всех тренеров
- `Trainer->Create()` - создать тренера
- `Trainer->Update()` - обновить данные тренера
- `Trainer->Delete()` - удалить тренера

### Посетители
- `VisitorUser->GetAll()` - список посетителей
- `VisitorUser->Create()` - добавить посетителя
- `VisitorUser->Update()` - обновить данные
- `VisitorUser->Delete()` - удалить посетителя
- `VisitorUser->Block()` - заблокировать
- `VisitorUser->Unblock()` - разблокировать
- `VisitorUser->VerifyOTP()` - проверить OTP код

### Аутентификация
- `SMS->SendOTP()` - отправить код подтверждения
- `AdminUser->Auth()` - авторизация администратора

## Функциональность SMS

Система использует **Mobizon API** для отправки SMS с кодами подтверждения.

**Параметры** (`config/config.php`):
- **URL**: https://api.mobizon.kz/service/message/sendSmsMessage
- **API_KEY**: ваш API ключ
- **FROM**: отправитель (SPetrenko)
- **VALIDITY**: срок действия OTP (5 минут)

**Использование**:
```php
$sms = new SMS();
$otp = $sms->SendOTP($phone_number);
```
